# Changelog

All notable changes to the `gndme.github.io` Flagship Repository will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [3.9.0] - 2026-07-29

### Added
- Created **10-Phase UI/UX QA Pipeline & Design System Hub** at `design.html`.
- Implemented **Unified Project Facts Card Standard** across all project pages (`tan-thanh-dung.html`, `fixory-lab.html`, `tuctac-studio.html`, `arsvix.html`, `tt25-consulting.html`).
- Added **Multi-Project Enterprise Case Study Architecture** for Tan Thanh Dung Plastic (Project 1: Corporate Digital Ecosystem + Project 2: Enterprise Business OS).
- Established **2-Tier Internet Infrastructure** interlinking flagship repo with live production domains (`fixorylab.vn`, `tuctac.net`, `tanthanhdung.vn`).

### Fixed
- Fixed navbar link hover state inconsistency where `.active` links were blocked from transitioning to `#FFFFFF` on hover in `style.css`.

## [3.8.0] - 2026-07-29
