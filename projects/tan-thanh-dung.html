Tan Thanh Dung is a Manufacturing Digital Transformation initiative created by gndme. Industrial MES deployment, supply chain tracking, and plant automation.

01. MISSION & VISION

Tan Thanh Dung represents a full-scale Industrial Digital Transformation case study. By deploying custom-architected Manufacturing Execution Systems (MES), automated inventory control, and secure Nginx/FastAPI backend infrastructure, the enterprise transitioned traditional plastic manufacturing workflows into a fully data-driven production facility.

03. OS CORE MODULES

[ MES & Workflow Engine ]

FastAPI & SQLite/PostgreSQL core managing real-time order lifecycle tracking.

[ Infrastructure & Security ]

Daemonized Ubuntu Server with PM2, Nginx reverse proxy, SSL, and strict UFW firewalling.

[ B2B Operations Portal ]

Client order status dashboard with automated invoice and packing slip generation.

04. DECOUPLED ARCHITECTURE & TECH STACK

  • Backend Engine: Python, FastAPI (Modular Monolith: Auth, Orders, Staff, Inventory)
  • Data Architecture: SQLite (File-based, SMB optimized) / PostgreSQL + SQLAlchemy ORM
  • Server Infrastructure: Ubuntu Server, PM2, Nginx SSL/TLS, UFW Firewall Isolation

05. AI & TELEMETRY LAYER

Tan Thanh Dung integrates telemetry analytics to predict logistics fulfillment lead times and optimize inventory re-order points across plant operations.

06. ROADMAP & EVOLUTION

Phase 1 (MES Core & Inventory Digitization) ➔ Phase 2 (Nginx/FastAPI Secure Deployment) ➔ Phase 3 (Automated Client B2B Dispatch Portal). Official portal: tanthanhdung.vn
