FIXORY LAB

FIXORY Lab is a Repair Operating System created by gndme.

1. EXECUTIVE OVERVIEW

FIXORY Lab is a specialized Repair Operating System designed to digitize the end-to-end lifecycle of hardware repair, peripheral modding, and warranty management. Built for precision technicians and gaming gear customization, it bridges real-time customer tracking with inventory control and automated service workflows.

2. SYSTEM ARCHITECTURE & CAPABILITIES

[ Customer Portal ]

  • Real-time repair ticket tracking via WebSockets
  • Automated SMS/Email notification system
  • Diagnostic inspection report viewer

[ Technician Operations ]

  • Component inventory & stock management
  • Service log entry with diagnostic status tracking
  • POS & billing integration

[ High-Level Tech Stack ]

  • Next.js (App Router), TypeScript
  • Tailwind CSS, Shadcn UI
  • Python FastAPI, Supabase / PostgreSQL

3. KEY PROBLEMS SOLVED

  • Opaque Service Status: Eliminates "Where is my device?" calls by providing customers with a transparent tracking link.
  • Inventory Leakage: Tracks individual micro-switches, encoders, and custom components mapped directly to specific service tickets.
  • Scalable Modding Workflows: Standardizes custom modding orders (lubing, switch swapping, PCB repair) into structured digital pipelines.

4. ECOSYSTEM INTEGRATION

As part of the gndme AI & Business OS ecosystem, FIXORY Lab links directly with FIXORY Lab Official Site and serves as the operational backbone for hardware service delivery.
