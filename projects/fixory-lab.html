FIXORY LAB

FIXORY Lab is a Repair Operating System created by gndme. Built to digitize hardware intervention, warranty tracking, component inventory, and custom gear modding.

01. MISSION | 02. WORKFLOW | 03. CORE MODULES | 04. ARCHITECTURE | 05. AI LAYER | 06. ROADMAP

01. MISSION & VISION

Traditional repair shops suffer from opaque diagnostic status, un-tracked component stock, and fragmented customer updates. FIXORY Lab operates as a dedicated Repair OS that digitizes every hardware intake, component replacement, and custom modding job into an auditable real-time pipeline.

02. OPERATIONAL WORKFLOW

[CUSTOMER INTAKE] ➔ [HARDWARE DIAGNOSTIC REPORT] ➔ [PARTS RESERVATION]
➔ [TECHNICIAN WORKBENCH] ➔ [QC TEST & VERIFICATION] ➔ [CUSTOMER DELIVERY & WARRANTY]

03. OS CORE MODULES

[ Client Tracking Engine ]

Real-time repair progress dashboard for end users with WebSocket status notifications.

[ Inventory & Parts POS ]

Granular tracking for micro-switches, encoders, PCBs, and custom modding stock.

[ Diagnostic Benchmark ]

Integrated peripheral testing algorithms for double-click, debounce, and scroll-wheel jitter.

04. DECOUPLED ARCHITECTURE & TECH STACK

  • Frontend Layer: Next.js (App Router), TypeScript, Tailwind CSS, Shadcn UI
  • Core API Engine: Python FastAPI (Daemonized), Modular Monolith Architecture
  • Data Persistence: Supabase / PostgreSQL + Redis State Cache
  • Deployment: Ubuntu Server, Nginx SSL Reverse Proxy, PM2 Process Manager

05. AI & DIAGNOSTIC LAYER

Fixory Lab incorporates diagnostic AI models to evaluate peripheral click signals, detect switch chattering via microsecond latency timing, and recommend exact component replacements or affiliate hardware upgrades.

06. ROADMAP & EVOLUTION

Phase 1 (Public Portal & Diagnostic Tools) ➔ Phase 2 (Next.js Strangler Fig Migration) ➔ Phase 3 (3D Desk Setup & Custom Gear Modder Integration). Official live service portal: fixorylab.vn
