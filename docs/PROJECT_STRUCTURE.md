# Project Directory Structure & Organization

This document details the file tree organization and purpose of each directory in `gndme.github.io`.

---

## 📂 Directory Layout

* **`.github/`**: GitHub repository governance, issue templates (`bug_report.md`, `feature_request.md`), PR template, and CODEOWNERS.
* **`docs/`**: Technical design documents (`ARCHITECTURE.md`, `DESIGN_SYSTEM.md`, `UI_QA.md`, `ROADMAP.md`, `CONTRIBUTING.md`, `CODING_STANDARDS.md`, `PROJECT_STRUCTURE.md`).
* **`content/`**: Structured JSON and Markdown datasets for brands, case studies, and journal essays.
* **`assets/`**: Media directory categorized by domain (`assets/images/brands/`, `assets/images/case-studies/`, `assets/images/ui/`, `assets/images/logos/`).
* **`styles/`**: Modular CSS engine split into 6 core files (`reset.css`, `tokens.css`, `layout.css`, `components.css`, `pages.css`, `utilities.css`).
* **`scripts/`**: ES Module JavaScript files (`cursor.js`, `navigation.js`, `scroll.js`).
* **`projects/`**: In-depth Technical Case Profiles and Enterprise Case Study HTML documents.
* **Root (`/`)**: Main entry point HTML pages (`index.html`, `brands.html`, `case-studies.html`, `journal.html`, `about.html`, `design-system.html`).
