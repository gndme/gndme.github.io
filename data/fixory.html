Founder: gndme | Category: Repair & Hardware Services | Web | FB | IG | TikTok

1. BUSINESS ARCHITECTURE

A fully digitized ecosystem for device intake, repair tracking, and delivery. The system's core value lies in absolute transparency via real-time customer tracking and optimized technician/inventory management.

2. APPLICATION ARCHITECTURE

[ Frontend / Client ]

  • HTML5, Vanilla JS, CSS3 (Utility-first)
  • Responsive Web Design, FOUT Optimization
  • Real-time AJAX/Fetch API & WebSockets

[ Backend / Core API ]

  • Python, FastAPI
  • Modular Monolith (Auth, Orders, Staff, Inventory)

3. DATA ARCHITECTURE

- DB Engine: SQLite (File-based, SMB optimized, easy backups)
- ORM: SQLAlchemy (PostgreSQL-ready for scaling)
- Core Entities:
  + Orders <--> Customer & Devices
  + Staff (Role, Status)
  + InventoryItem (Component Input/Output)
  + ServiceTicket (Device-attached service logs)

4. DEPLOYMENT & SECURITY

  • Infrastructure: Ubuntu Server Environment with PM2 process management.
  • Reverse Proxy: Nginx domain resolution, SSL/TLS Let's Encrypt.
  • Firewall: UFW configured for comprehensive security, blocking internal port access (FastAPI daemonized).
