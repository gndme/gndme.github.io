FIXORY LAB - SERVICE MANAGEMENT SYSTEM

Founder: gndme | Category: Repair & Hardware Services

1. BUSINESS ARCHITECTURE

Số hóa toàn diện quy trình tiếp nhận, sửa chữa, theo dõi và bàn giao thiết bị. Hệ thống mang lại giá trị cốt lõi là sự minh bạch (Tracking realtime) và tối ưu quản lý Kỹ thuật viên & Tồn kho.

2. APPLICATION ARCHITECTURE

[ Frontend / Client ]

  • HTML5, Vanilla JS, CSS3 (Utility-first)
  • Responsive Web Design, FOUT Optimization
  • Real-time AJAX/Fetch API & WebSockets

[ Backend / Core API ]

  • Python, FastAPI
  • Modular Monolith (Auth, Orders, Staff, Inventory)

3. DATA ARCHITECTURE

- DB Engine: SQLite (File-based, tối ưu cho SMB, backup dễ dàng)
- ORM: SQLAlchemy (Sẵn sàng scale lên PostgreSQL)
- Core Entities:
  + Orders <--> Customer & Devices
  + Staff (Role, Status)
  + InventoryItem (Linh kiện xuất/nhập)
  + ServiceTicket (Dịch vụ đính kèm thiết bị)

4. DEPLOYMENT & SECURITY

  • Infrastructure: Linux VPS (Ubuntu) quản lý tiến trình bằng PM2.
  • Reverse Proxy: Nginx phân giải tên miền, SSL/TLS Let's Encrypt.
  • Firewall: UFW bảo vệ toàn diện, chặn truy cập cổng nội bộ (FastAPI chạy ngầm).
