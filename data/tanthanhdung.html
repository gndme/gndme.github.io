TAN THANH DUNG PLASTIC - ENTERPRISE ARCHITECTURE

Architected & Operated by: CW Group (gndme) | Category: Manufacturing Execution System

1. EXECUTIVE SUMMARY

Hệ sinh thái số hóa toàn diện bao gồm thương mại điện tử, quản trị nội bộ và điều hành sản xuất. Thiết kế theo kiến trúc Micro-Frontends & API-First, đảm bảo khả năng mở rộng, tính linh hoạt và tối ưu hóa UX & GEO SEO.

2. BUSINESS ARCHITECTURE

[ Khách hàng B2B/B2C ]

  • Trải nghiệm mua sắm trực quan
  • Tra cứu thông tin nhựa siêu tốc

[ Vận hành Back-office ]

  • Số hóa quy trình đơn hàng
  • Quản lý danh mục & Khách hàng

[ Khối Sản xuất Nhà máy ]

  • Theo dõi tiến độ, vật tư
  • Ứng dụng nghiệp vụ phân xưởng

3. APPLICATION ARCHITECTURE (MICRO-FRONTENDS)

[fe-public]   -> Tối ưu SEO (SSR/SSG), tải trang siêu tốc, JSON-LD chuẩn GEO SEO.
[fe-admin]    -> Tối ưu CSR (Tailwind CSS Sidebar), quản lý lượng lớn dữ liệu nội bộ.
[plastic_mfg] -> Industrial UX chống lỗi (Poka-yoke) dùng trên di động & máy công nghiệp.
-------------------------------------------------------------------------------------
[Core API]    -> RESTful/GraphQL (Single Source of Truth) xử lý Logic và phân quyền.

4. DATA ARCHITECTURE & SECURITY

  • Database: PostgreSQL (Supabase) tích hợp Row-Level Security (RLS).
  • Entities: Users/Roles, Products, Orders, Mfg_Orders, Materials.
  • Security Bypass: Dữ liệu Public được mở khóa. fe-admin & plastic_mfg bị cô lập chặt chẽ ở cấp CSDL.

5. TECHNOLOGY STACK & DEPLOYMENT

[ Tech Stack ]

  • Front: Next.js 14, React Native
  • Style: Tailwind CSS, Lucide
  • Back: Express / FastAPI

[ Server & Ops ]

  • Linux VPS (Ubuntu) + PM2
  • Nginx Reverse Proxy & Load Balance
  • CI/CD (Github Actions + SSH)

6. BRANDING & STRATEGY

Tích hợp LocalBusiness JSON-LD thống trị Google Maps địa phương. Áp dụng chiến lược "Personal Brand backed by Corporate Brand", hệ sinh thái Tân Thanh Dung đã khép kín toàn bộ chuỗi cung ứng từ Nhà máy -> Back-office -> Khách hàng.
