TUCTAC STUDIO - E-COMMERCE ARCHITECTURE

Founder: gndme | Category: Premium Niche E-Commerce (Collectible Figure Craft)

1. BUSINESS ARCHITECTURE

Nền tảng thương mại điện tử chuyên biệt (Niche E-commerce) phục vụ giới sưu tầm mô hình cao cấp. Xây dựng hệ sinh thái khép kín giúp khách hàng khám phá sản phẩm mượt mà (B2C), đồng thời giúp đội ngũ quản lý dữ liệu tập trung.

2. APPLICATION ARCHITECTURE

[ Web Storefront ]

  • Next.js (App Router), React
  • Tailwind CSS, Framer Motion
  • Tối ưu SEO mạnh (SSR/SSG), Cinematic Dark-mode

[ Internal Admin ]

  • React (Vite), Tailwind CSS
  • Quản lý Products, Orders, Blogs
  • Thao tác nhanh gọn, trực quan

[ Core Backend ]

  • Node.js, Express
  • RESTful APIs chuẩn mực
  • Bảo mật, hiệu năng chịu tải cao

3. DATA ARCHITECTURE

- DB Engine: PostgreSQL (Đảm bảo toàn vẹn giao dịch B2C)
- ORM: Sequelize
- Core Entities:
  + Users / Admins (Danh tính & Phân quyền)
  + Products / Categories (Phân cấp sản phẩm)
  + Orders (Vòng đời thanh toán, vận chuyển)
  + Blogs (Quản trị nội dung & SEO)

4. INFRASTRUCTURE & ROADMAP

  • Infrastructure: Linux/Ubuntu VPS, Nginx Reverse Proxy điều hướng Web/Admin/API, PM2 Process Manager.
  • Security & Deploy: JWT Auth, Strict CORS, HTTPS/SSL, CI/CD Pipelines (Bash/Python/Github).
  • Future Roadmap: Payment Gateway, Meta API Sync (IG/FB), Redis Caching chịu tải Flash Sale.
